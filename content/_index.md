I'm Farough (Frank) Darakhshan. I work in water-damage restoration in Northern Virginia, and I build the software that runs the back office: invoicing, claim tracking, adjuster mail, and the to-do list my team works from.

This site documents the part of that work that is public. My GitHub account is [FrankDark007](https://github.com/FrankDark007).

## What is public

- **[aries-cloud-dashboard](/aries-cloud-dashboard/)**: a Cloudflare Workers and D1 board that shows my assistant's task list to the team and queues their actions. JavaScript.
- **[Aries-Board--GAIS-upgrades](/aries-board-gais-upgrades/)**: a redesign of that board's interface with a local preview server. JavaScript and TypeScript.
- **[Dot-Projects-Board](/dot-projects-board/)**: a mission control dashboard for live projects and workers, built to show only verified state. TypeScript.

Each page says what the code does, what it runs on, and how to start it.

## What is private, and why

Most of my code stays private because it sits next to customer records, claim files and price catalogs. A repo like that cannot be published without leaking someone's address or claim.
